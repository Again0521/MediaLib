# MediaLIB

### 映画、ドラマ、アニメ、音楽、写真。すべてが、ひとつの家に。

macOS ネイティブのホームメディアライブラリ。ローカルディスク、外付けドライブ、NAS、そして Emby・Jellyfin・Plex に散らばったコンテンツを、すっきりと美しく、心地よいひとつのアプリにまとめます——見る・探す・再生する、すべてをここで。

## まず、いちばん大切なこと

> **MediaLIB が管理するのは「インデックス」と「キャッシュ」——あなたのファイルそのものではありません。**

スキャン、分類、お気に入り、見たいリスト、評価、再生履歴、プレイリスト、アートワーク、メタデータの修正——これらはすべて、初期状態では MediaLIB 自身のデータの中だけに保存されます。あなたのメディアファイルを**移動も削除もリネームも一切しません**。

唯一の例外は、音楽タグワークベンチで**自分の手で「ファイルに書き込む」を有効にしたとき**だけ。そのときに限り、音声ファイルのタグに触れます。それ以外では、あなたの元のコレクションはそのまま保たれます。

## 映画とシリーズを、きちんと整理

映画、ドラマ、アニメ、ドキュメンタリー、バラエティ——それぞれの居場所へ。シリーズは作品・シーズン・話数で自動的にまとまり、すでに整理済みのものから先に表示され、残りは順に埋まっていきます。

- **見やすく** — 均等に並ぶポスターウォール。カーソルを乗せるとふわりと浮き上がり、評価バッジも一目で。
- **扱いやすく** — お気に入り、見たいリスト、視聴済み／未視聴／視聴中、5 段階評価。すべて右クリックで。
- **まとめやすく** — 手動コレクションとスマートコレクション。お気に入りのまとまりはホームに掲載も。
- **見分けやすく** — TMDB でポスター、あらすじ、キャストとスタッフ、スチル、関連作品、人物プロフィールを補完。

## 写真を、ローカルとシステムで一緒に

写真セクションは、ローカルの動画・写真と、macOS の**システム写真**ライブラリを同じページにまとめます。システム写真は PhotoKit を通じてリアルタイムに読み込まれ、**MediaLIB に複製されることはありません**。日付ごとのグループ化、連続スワイプ、ピンチによるズーム、2 本指でのパンに対応し、iCloud のオリジナルをダウンロードするときは進捗も表示されます。

## ひとつの鍵で、プライベートを守る

**保管庫（ボールト）**は、見られたくないものをしまっておく場所。ロック中は、そのパス、ファイル名、ソース、件数が漏れることはなく、ホーム、視聴済み、お気に入り、人物の出演作にも一切現れません——まるで、はじめから存在しなかったかのように。初回に 4〜8 桁の PIN 設定を案内し、以降は Touch ID でワンタッチ解錠できます。

![保管庫](asset/vault-locked.png)

<br>

## あなたのメディアを、どこにあっても

**メディアソース**では、ローカルフォルダ、外付けドライブ、マウント済みの NAS、そして Emby・Jellyfin・Plex サーバーを一箇所で管理できます。リモートサーバーは独立したディレクトリとして表示され、ローカルコンテンツに混ざることはありません——オフラインになっても、ファイルを削除済みと誤認しません。

![メディアソース](asset/media-sources.png)

<br>

## 状況がひと目でわかるダッシュボード

**ダッシュボード**は、ライブラリの健全性、バックグラウンドタスク、対応が必要な事項を一画面にまとめます：どのソースがオンラインか、失われたファイルはないか、アートワークとメタデータは揃っているか、オフラインキャッシュをどれだけ使っているか。ワンタップのクリーンアップで、いつも清潔に。

## 十分すぎるほどのプレイヤー

内蔵ビデオプレイヤーは、アプリに同梱された **libmpv** を採用し、ネイティブウィンドウで描画されます——赤・黄・緑のボタンもシステムの角丸もそのまま：

| 再生 | 字幕と音声 | 上級 |
| :-- | :-- | :-- |
| 一般的なコンテナと MKV | 内蔵／同一フォルダの外部字幕 | チャプター、ブックマーク、OP/ED マーカー |
| 速度、音量、フルスクリーン、最前面 | 複数音声トラック | A-B ループ、単一ループ、自動で次の話 |
| スナップショット、フレームプレビュー、残り時間 | オンライン字幕の検索とダウンロード | リモート画質選択、オフラインキャッシュ |

## はじめかた

**動作環境**：macOS 13 Ventura 以降。ローカルのスキャンと再生に**アカウントは不要**です。TMDB のスクレイピング、音楽メタデータ、リモートサーバー、字幕ダウンロードなどのネットワーク機能には、対応するサービスのアカウントまたは API キーが必要です。

`MediaLib.dmg` を入手したら：

1. DMG を開く；
2. `MediaLIB.app` を「アプリケーション」にドラッグ；
3. ローカルビルドの初回起動時は macOS がブロックすることがあります。アプリを右クリックして**開く**を選び、もう一度確認してください。

<br>

## ソースからビルド

```bash
brew install mpv ffmpeg
env DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build
env DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift run MediaLibChecks
scripts/package_dmg.sh
```

生成物は `dist/MediaLIB.app` と `dist/MediaLib.dmg` です。

## データ保護の原則

<details>
<summary><b>あなたのデータについての、MediaLIB からの 7 つの約束</b></summary>

<br>

- スキャンは内部インデックスの作成・更新のみで、メディアファイルは変更しません。
- 再分類は MediaLIB 内部のカテゴリーのみを編集します。
- お気に入り、見たいリスト、評価、再生履歴、コレクション、プレイリストはローカルインデックスに保存されます。
- 無効なインデックスの整理には確認が必要で、削除するのはインデックスのみ。ファイルは削除しません。
- オフラインキャッシュは、MediaLIB 自身が生成したキャッシュのコピーのみを管理します。
- データベースのバックアップと復元は内部データのみを置き換え、ソースのメディアファイルには触れません。
- 保管庫がロックされている間、プライベートなパス・名前・件数が漏れることは一切ありません。

</details>
